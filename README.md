# auth-demo

Навчальний модуль автентифікації на Node.js: реєстрація і вхід користувачів
зі збереженням облікових записів у пам'яті.

## Встановлення

Потрібен Node.js 18 або новіший. Залежностей немає.

## Використання

    node src/cli.js signup <логін> <пароль>
    node src/cli.js login <логін> <пароль>

Статус: прототип.
